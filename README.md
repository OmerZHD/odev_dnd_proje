# D&D Tanıtım Kulübü

Bu proje, Dungeons & Dragons tanıtım kulübünün HTML ve CSS ile hazırlanmış statik web sitesidir.

## Web Sitesini Çalıştırma

1. Terminalde proje klasörüne girin:

```powershell
cd C:\Users\user\Desktop\odev_dnd_proje\odev_dnd_proje
```

2. Yerel web sunucusunu başlatın:

```powershell
py -m http.server 8080 --bind 127.0.0.1
```
Sunucuyu durdurmak için terminalde `Ctrl+C` tuşlarına basın.
